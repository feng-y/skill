# 当 PASS 可能撒谎

只在普通验收之外还存在一个具体风险：**实现其实错了，但当前检查仍可能显示 PASS** 时读取。通用的“不能靠削弱判据制造成功”由 [execution-compile.md](execution-compile.md) 负责，这里只决定是否需要额外反证。

先说清失败会怎么漏过去。常见情况是：检查没有真正观察目标；实现者能绕过判据；固定样本很容易被针对；失败不会传播；关键结论只能靠实现者自己宣称。

然后只补能反证这个风险的最小检查。例如制造一次受控失败确认报警真的会响，换一个实现者事先不知道的样本，或让未参与实现的主体在权威环境重新取证。额外检查必须来自同一个 Goal，不能偷偷增加新要求。

必要反证拿不到时就准确报告 evidence gap，不能降级成 PASS。
