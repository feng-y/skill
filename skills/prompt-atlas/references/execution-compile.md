# Execution Compile

Use only for Stage 2 edge cases; `SKILL.md` is the rule source.

## Task 0

Task 0 is fixed, not heavy. It binds the actual repo/worktree/target, validates the taskbook, and routes disagreement before material change. Reuse authoritative evidence that is fresh and applies to the same execution object; recheck only missing, stale, disputed, environment-dependent, or invalidated facts.

If reality differs, revise the remaining graph when intent and boundaries still hold; return to Intent Take when they would change; park only a blocked branch while safe work remains; otherwise block with the exact resolving condition. Never defer a visible Human decision to Task 0.

## Graph and state

Start with:

```text
Task 0 → Execute with local proof → Global Gate
```

Add structure only when it changes dependency, ownership, evidence, invalidation, joins, or routing. Give shared mutable surfaces one owner. The Executor may revise remaining work inside the frozen Goal, boundaries, and proof obligations, recording material changes in `PROGRESS.md`.

`PROGRESS.md` keeps completed/current/next work, evidence, stale evidence, parked branches, and remaining Goal conditions. `BLOCKED.md` exists only for a real blocker. Both stay concise under `.scratch/<project>/` and are not committed.

Retries must change the hypothesis or approach. Stop known-bad paths immediately; three failures against the same acceptance condition in one route force replan, branch switch, rollback, `BLOCK`, or `ESCALATE`.

Keep one taskbook small enough to close as one execution effort; otherwise split it.
