# When Goal is not settled yet

Read only after the main Skill has begun Ground / Shape but still cannot form a Stable Goal. This file does not redefine Unknown routing; it handles two judgments that commonly make Goal wrong.

## Semantic altitude

To decide whether a statement belongs in Goal or should remain with the Executor, use this test:

> **Would the Human still accept it if a materially different implementation satisfied the same requirement?**

Yes → it is usually How / intelligence and Prompt Atlas should not freeze it.

No → it expresses a result, boundary, risk commitment, or Verification requirement the Human actually cares about and belongs in Goal.

A concrete current implementation, class/provider, or detailed existing plan does not automatically elevate How into Goal. Conversely, when the Human explicitly requires a representation / compatibility / provider because that representation itself is a business or technical commitment, it may be part of Goal.

## Map is not territory

The prompt, current plan, and Prompt Atlas itself are maps. The repo, runtime, historical constraints, and real consumers may expose facts the map omitted but that can still change Goal.

Follow only those differences: authoritative specs or precedents, real consumers, external contracts, serialized/config identity, deployment or authorization constraints, and the real relationship between current workspace work and Human Goal. These are lenses, not a checklist.

For each candidate ask: **would another value produce a different Stable Goal?** If not, stop expanding.

## Decision priority

When Human requirements genuinely conflict, Stable Goal must tell the Executor what wins. Priority can come only from the Human, existing authority, or an unavoidable reality constraint; Prompt Atlas must not reorder it merely because one implementation is easier.

If reality resolves the conflict, converge directly. Otherwise surface the remaining Human-owned conflict together with the main consequences and a recommendation.

## Stop shaping

When every remaining question can change only How rather than the Goal the Human will accept, stop Intent Research and return to Compile. New Unknowns during implementation are normal; Prompt Atlas does not need to eliminate them before execution.
