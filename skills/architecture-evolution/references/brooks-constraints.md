# Brooks 反证

只在 Target 已成立，但候选 Evolution Program 看起来可能只是把复杂度搬家、增加第二套结构或为未来搭脚手架时读取。Target judgment 属于 `$architecture-shape`；这里只挑战当前 Program 是否值得推进。

1. **Program 是否仍由少量一致的结构变化解释？** 独立 responsibility 可以保留，不为了统一而合并；同一 correction 也不要拆成多层协调。
2. **新结构是在消除复杂度，还是只包住复杂度？** 如果旧 authority、重复知识、兼容残留或特殊路径没有 real exit，新 facade / layer 不是收益。
3. **是否正在建设“第二个系统”？** 没有当前 Program 所需的真实 gap，不预建通用扩展、模式、钩子、注册表或框架。

反证成立就缩小、替换或取消 Program；若问题实际上证明 Target premise 失效，返回主 Skill 重新进入 `$architecture-shape`，不要在这里重做 Target。最终交付不输出 Brooks 名称、评分或推理轨迹。
