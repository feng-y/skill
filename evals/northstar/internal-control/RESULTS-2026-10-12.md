Source signal: F18 in the feedback ledger, sourced to the DaVinci project feedback
log and the Human correction that handoff is optional and the skill must control
its own behavior. The incident already violated the existing authorization rule.

## Change

The entry description and primary rule now identify independent Northstar's
default deliverable as the plan. Target behavior supplies Draft meaning; it does
not automatically authorize implementation. Convergence, readiness, scoped
authorization and ongoing Intent context are composed into one internal action
model. Readiness selects no implementation by itself. Explicit implementation
authorization is still used autonomously, including in the same host, and returned
results are judged against the same plan. No external agent, handoff, persistent
state or new lifecycle is required. The existing implementation-How and Verify
responsibilities remain separate from Northstar's Intent judgment.

The entry YAML and material-compile reference are aligned. Duplicate main-body
paragraphs and mandatory-sounding handoff wording were removed. This is an
existing-owner contract clarification, not a breaking responsibility migration.

candidate P remain plan-only and candidate I complete implementation/review.
Their summaries and local raw-record pointers are retained separately in the
evidence archive. They are not
combined with the final table: one base used external delegation despite the CLI

that Task defect was removed from both arms before the complete pairs. None of
these incomplete/different-environment attempts counts as behavioral PASS.

This is a bounded smoke, not statistical uplift or proof against all wording,
models, compaction or session recovery conditions. It exercises a small Python
feature/score/response model, not the production C++ service or shared_ptr pool.
The host cannot run workspace-write bwrap, so the final actors use unsandboxed
disposable homes/workspaces; this is not an adversarial host-isolation claim.
Snapshots detect mutations at tool boundaries; within-command edit/revert still
requires inspecting the full command. The UI default prompt was aligned by
inspection; this run measures native CLI SKILL loading, not UI invocation.

Static validation passed for frontmatter, local links and the runner. The fixture's
two original behavior tests and the existing controller/worker backend's 27
self-tests pass. Backend self-tests do not count as Northstar behavior evidence.
The repair changes the skill repo only; no installed-home synchronization or
DaVinci product changes are part of this repair.
