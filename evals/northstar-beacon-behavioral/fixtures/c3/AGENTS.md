# Protobuf SDK design fixture

`docs/accepted-context.md` contains already accepted surrounding decisions and
must remain unchanged. For a request to make the accessor interface concrete,
put the reviewable local draft in `docs/accessor-interface-draft.md`.

There is no product implementation in this fixture. Keep the artifact limited
to the requested local interface shape; do not create an issue graph,
implementation plan, verification workflow, or second canonical product spec.
